# Identidade do MolaStruct

O nome exibido é **MolaStruct**. A arte oficial é a figura da Terra sustentando uma mola e uma fundação, sobre fundo azul, disponibilizada no [acervo do projeto](https://drive.google.com/drive/folders/1ElqJm_rrymSJ_tyf6OQnALOnErVC9fSY).

- Original: `MolaStruct_Icone_Original_1254x1254.png`, 1254 × 1254 pixels, preservado no Drive.
- Interface, favicon, relatório e README: `public/molastruct-icon.png`, PNG RGBA de 512 × 512 pixels.
- Pacotes nativos: PNG de 32, 64, 128, 256 e 512 pixels, ICO multirresolução para Windows e ICNS para macOS em `src-tauri/icons/`. Todas as versões derivam da mesma arte, sem redesenho.
- Menu Linux: o Struct Launcher 0.2.3 ou posterior instala o PNG próprio e identifica a janela pelo binário `molasstruct`.

Os identificadores internos `molasstruct`, `com.openstruct.molasstruct`, as chaves de armazenamento e o formato dos arquivos de projeto foram mantidos para compatibilidade com os projetos existentes. O nome comercial e os ícones não dependem desses identificadores.

A identidade está aplicada à linha atual do projeto. O pacote 0.5.1 contém essa mesma correção sobre a base publicada 0.5.0.
