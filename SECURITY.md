# Segurança

A linha 0.1.x está em desenvolvimento experimental. Correções são direcionadas à versão mais recente; não há compromisso de manutenção de versões anteriores.

Para vulnerabilidades envolvendo execução de código, acesso indevido a arquivos ou exposição de dados, utilize o relato privado de vulnerabilidades do GitHub se estiver habilitado. Caso não esteja disponível, abra uma issue solicitando um canal privado, sem publicar a exploração ou dados sensíveis.

Erros de cálculo devem ser relatados pelo modelo **Erro ou divergência de cálculo**, com caso fictício, unidades, hipóteses e referência esperada. Consulte os limites do motor em [MOTOR.md](docs/MOTOR.md).
